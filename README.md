# Wild West Horticulture Website

Basic Vite/React website for Wild West Horticulture.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to Netlify
1. Upload this project to GitHub, or drag the project folder into Netlify.
2. Build command: `npm run build`
3. Publish directory: `dist`
4. After deployment, go to Netlify > Forms and enable email notifications to wildwesthorticulture@gmail.com.

The contact form will not send in local preview. It needs Netlify Forms or another form backend.
